# CapstoneProject

Monorepo gom 3 phan cua he thong SkinDeseases:

- `FE/`: frontend Next.js, tu repo `SkinDeseases-FE`.
- `API/`: backend API chinh, tu repo `SkinDeseases-API`.
- `AI-API/`: AI inference/chatbot API, tu repo `SkinDeseases-AI-API`.

## Ghi chu

- Khong commit `.env`, dependency/build cache, virtualenv.
- File model lon nhu `.pth`, `.pt`, `.onnx` khong duoc dua vao repo nay. Neu can luu model tren GitHub, hay dung Git LFS.
